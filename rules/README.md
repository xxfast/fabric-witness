# Rules

Two separate catalogs live here.

- **[witness/](witness/README.md)** — the line-puzzle rules from *The Witness* that this mod
  replicates: how the drawn path works and how each panel symbol validates. About the *puzzle*.
- **[minecraft/](minecraft/README.md)** — the mod's own crafting rules: how puzzle panels are
  built, grown, recoloured, and recycled at a crafting table. About the *item*.

They do not overlap: a `witness/` file never mentions Minecraft crafting, and a `minecraft/` file
never validates a puzzle solution.
